# Liao2026 与 Sun2026：用于 4D 打印承载折纸吸波论文的写作逻辑

> 适用稿件：连续纤维增强 4D 打印承载型折纸电磁超结构，用于可编程微波吸收  
> 核心目标：把 Liao2026 的“4D 打印输入-结构-性能映射”与 Sun2026 的“Miura-ori 承载-宽带吸波结构工程”融合为当前文章的写作骨架。  
> 使用方式：后续撰写 Introduction、Results and discussion、图注和 Discussion 时，优先参考本档案。

## 1. 两篇文章分别提供什么

### 1.1 Liao2026 Advanced Materials 的作用

文章主题：

**Bioinspired 4D-Printing Microwave Absorbers With Adaptive Programmable Switches via Morphable Percolation Networks and Resonant Models**

可借鉴的核心不是“仿生”或“LCE/FCIP”，而是它把 4D 打印吸波器写成一个可预测的多物理映射系统：

```text
thermal excitation -> structural morphology -> electromagnetic response
```

其写作重点包括：

- 将静态吸波器的瓶颈定义为固定结构-频率关系。
- 将 4D 打印的价值定义为把外部刺激转化为可控形态变化。
- 将形态变化进一步转化为阻抗匹配、谐振和损耗网络变化。
- 用双尺度机制解释性能提升：宏观 cavity / topology + 微观 percolation network。
- 用循环稳定性和实际热源触发证明 4D 调控不是概念展示。

对当前稿件的启发：

```text
electrothermal activation -> locked origami morphology -> microwave absorption/scattering response
```

当前稿件不能照搬它的仿生皮肤、LCE、拱形 cavity 和 percolation network 叙事，但可以吸收它的逻辑：**输入、结构和性能之间要形成确定映射**。

### 1.2 Sun2026 Composites Science and Technology 的作用

文章主题：

**High-load-bearing and ultra-wideband absorbing reconfigurable Miura-ori metastructures**

可借鉴的核心是它把 Miura-ori 写成一种同时服务电磁吸收和结构承载的工程构型：

```text
rigid-flexible Miura-ori -> folding state -> broadband absorption + load-bearing -> RCS reduction
```

其写作重点包括：

- 从可重构吸波器的工程限制进入，指出纸基/薄膜折纸结构力学脆弱。
- 用刚性面板、柔性铰链和 FDM 一体化制造建立结构基础。
- 先做几何参数优化，再研究折叠角对吸波的影响。
- 用电场、损耗场解释峰谷结构、多重散射和边缘衍射。
- 单独验证压缩承载和能量吸收。
- 最后将折纸结构组装为功能板，测试 RCS 降低。

对当前稿件的启发：

```text
Miura-ori geometry -> locked folding angle -> absorption band tuning + load transfer
```

当前稿件不能照搬它的机械重构逻辑，因为本研究的关键不是外部机械折叠态扫描，而是 **4D 打印电热激活、机械设定和冷却锁定形成稳定折叠角状态**。

## 2. 当前文章应如何融合两篇逻辑

当前文章最合理的总逻辑是：

```text
load-bearing microwave management demand
-> fixed absorbers and mechanically reconfigurable structures are insufficient
-> rGO/FCI/PLA provides magneto-dielectric loss and shape-memory locking
-> continuous fibers provide load-transfer and Joule-heating channels
-> Miura-ori geometry converts locked folding angle into electromagnetic design variable
-> global folding-angle tuning shifts absorption bands
-> unit-level morphology coding regulates array-scale backscattering
```

一句话核心贡献：

> 本文不是简单提出一种折纸吸波结构，而是将锁定折叠形态转化为承载型吸波器中的可编程电磁响应变量。

英文核心表达：

> This design converts the locked folding morphology into a programmable electromagnetic variable in a load-bearing absorber.

## 3. Introduction 的融合写法

### 3.1 可以借鉴 Liao 的问题定义

Liao 的开头逻辑：

```text
static absorbers -> fixed structure-frequency relationship -> need dynamic devices
```

当前稿件对应写法：

```text
traditional coatings/honeycomb absorbers -> fixed geometry and limited load-bearing contribution -> need load-bearing and tunable structural absorbers
```

可用中文句式：

> 固定几何和固定材料参数的吸波器件在制造完成后通常只能服务于有限频段，难以适应频率捷变探测、复杂入射角和平台姿态变化引起的电磁边界条件变化。

> 因此，承载型吸波结构的关键挑战不再只是提高单一频段吸收强度，而是如何在结构服役条件下实现可锁定、可编程的电磁响应。

可用英文句式：

> The key challenge is no longer limited to increasing the absorption intensity at a fixed frequency, but lies in enabling lockable and programmable electromagnetic responses under structural service conditions.

### 3.2 可以借鉴 Sun 的结构工程瓶颈

Sun 的开头逻辑：

```text
reconfigurable EM absorbers -> mechanical reconfiguration is attractive -> paper/film origami is fragile -> rigid-flexible Miura-ori solves deployability and load-bearing
```

当前稿件对应写法：

```text
origami absorbers can tune EM response -> many rely on flexible films or mechanical folding -> load-bearing, shape locking, and frequency programming remain insufficient
```

可用中文句式：

> 折纸构型能够有效耦合电磁吸收与力学承载性能，但现有可重构响应主要依赖外部机械折叠，对形态锁定和频段编程的支持仍然有限。

> 折纸吸波结构向结构型可调电磁构件转化的关键挑战，在于如何使同一折纸构件同时具备稳定承载、可锁定形态和频段可编程吸收能力。

### 3.3 当前 Introduction 最后的贡献句

建议固定为：

> 本文提出一种连续纤维增强的 4D 打印承载型折纸电磁超结构，实现可调电磁响应、结构承载和微波吸收的一体化设计。该结构以 rGO/FCI/PLA 形状记忆吸波复合体系提供介电/磁损耗和形态锁定基础，并通过连续纤维贯穿折纸面板与折痕区域，形成兼具载荷传递、电热激活和几何稳定能力的折纸构件。与依赖材料本征电磁参数实时变化或外部机械重构的可调吸波器不同，该结构通过电热展开、机械折叠和冷却锁定相结合的编程方式，将折纸构件锁定在不同折叠角状态。锁定后的折纸形态改变等效厚度、传播路径和局域场分布，使吸收峰在多个雷达波段之间迁移。进一步地，不同折叠角单元可组成形态编码阵列，实现阵列尺度的后向散射调控。该策略将连续纤维增强、4D 打印形态锁定和折纸几何调控结合起来，使锁定折纸形态成为承载型吸波器中的可编程电磁响应变量。

## 6. 当前稿件最适合采用的机制框架

建议不要直接使用 Liao 的 “Trap and Dissipate” 原词，但可以建立自己的双尺度机制。

### 6.1 中文机制框架

> 本文的吸波调控来自材料损耗和折纸形态的双尺度耦合。在材料尺度上，rGO/FCI/PLA 复合基体提供介电损耗、磁损耗和界面极化，连续纤维进一步调节有效介电响应并提供焦耳热激活通道。在结构尺度上，锁定折叠角改变等效厚度、传播路径和面板间耦合，使局域场和阻抗匹配条件随形态状态发生重构。两者共同使折纸形态从几何展开状态转化为可编程电磁响应变量。

### 6.2 英文机制框架

> The absorption modulation originates from a dual-scale coupling between material loss and origami morphology. At the material scale, the rGO/FCI/PLA matrix provides dielectric loss, magnetic loss and interfacial polarization, while the continuous fibers further regulate the effective dielectric response and provide Joule-heating pathways. At the structural scale, the locked folding angle modifies the effective thickness, propagation path and panel-to-panel coupling, thereby reconfiguring the local field distribution and impedance-matching condition. This coupling converts the origami morphology from a deployment state into a programmable electromagnetic variable.

```text
4D-printed shape locking + electrothermal activation + continuous fiber reinforcement + morphology-coded programmable absorption
```

避免表述：

- “我们首次实现 Miura-ori 承载吸波。”
- “Miura-ori 本身就是核心创新。”
- “高承载宽带吸波是唯一贡献。”

推荐表述：

> 已有高承载 Miura-ori 吸波结构证明了折纸构型在承载和吸波中的价值，但其可重构响应主要依赖外部机械折叠。本文进一步将电热激活和冷却锁定引入连续纤维增强折纸构件，使折叠角成为可设定、可保持和可编码的电磁状态。

### 7.2 不能写成 Liao 的重复

Liao 的核心：

```text
bioinspired LCE/FCIP + thermal actuation + flat-to-arched transition + percolation network evolution
```

当前稿件需要突出：

```text
rGO/FCI/PLA + continuous fibers + electrothermal activation + mechanical folding + cooling lock + load-bearing origami
```

避免表述：

- “热刺激直接驱动结构自动折叠到目标角度。”
- “微观填料网络随形态变化发生主导性重构。”除非有直接证据。

推荐表述：

> 本文的 4D 编程并非依赖热刺激直接决定最终形态，而是通过电热激活降低基体刚度，再经机械设定和冷却锁定获得目标折叠角。这一机制使折纸构件能够在无持续外场输入下保持稳定吸波状态。
