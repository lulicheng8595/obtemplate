# 课题知识索引

## 知识卡

```dataview
TABLE topic, status, linked_papers, linked_experiments
FROM "课题知识库"
WHERE type = "knowledge-card"
SORT file.mtime DESC
```

## 研究问题

```dataview
TABLE question, priority, evidence_status, next_action
FROM "课题知识库"
WHERE type = "research-question"
SORT priority DESC, file.mtime DESC
```
