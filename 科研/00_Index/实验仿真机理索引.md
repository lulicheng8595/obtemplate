# 实验仿真机理索引

## 实验记录

```dataview
TABLE date, project, material_system, objective, conclusion
FROM "实验仿真机理"
WHERE type = "experiment-record"
SORT date DESC
```

## 仿真记录

```dataview
TABLE date, software, model, objective, conclusion
FROM "实验仿真机理"
WHERE type = "simulation-record"
SORT date DESC
```

## 机理卡

```dataview
TABLE mechanism, evidence_level, linked_papers, open_questions
FROM "实验仿真机理"
WHERE type = "mechanism-card"
SORT file.mtime DESC
```
