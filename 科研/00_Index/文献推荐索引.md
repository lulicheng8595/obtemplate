# 文献推荐索引

## 推荐规则

优先收录与以下方向高度相关的文献：
- 4D printing / shape memory / reconfigurable structures
- direct ink writing / additive manufacturing
- electromagnetic wave absorption / microwave absorption
- high-entropy ceramic / high-entropy oxide / porous carbon
- metamaterial / metastructure / metasurface / radar stealth

## 推荐记录

```dataview
TABLE date, topic, priority, query, decision
FROM "文献推荐"
WHERE type = "literature-recommendation"
SORT date DESC
```

## 高优先级待读

```dataview
TABLE title, reason, doi, status
FROM "文献推荐"
WHERE contains(priority, "high") OR contains(priority, "必读")
SORT file.mtime DESC
```
