# Obsidian 科研模板包

这套模板用于把后续与 Codex 交流的论文相关内容系统化保存到 Obsidian。

适用范围：
- 文献推荐
- 论文阅读
- 实验、仿真与机理分析
- 课题知识库沉淀

建议放入 Obsidian Vault 后保持以下结构：

```text
ResearchVault/
  00_Index/
    科研主页.md
    文献推荐索引.md
    论文阅读索引.md
    实验仿真机理索引.md
    课题知识索引.md
  Templates/
    01_文献推荐记录.md
    02_论文阅读笔记.md
    03_实验记录.md
    04_仿真记录.md
    05_机理分析卡.md
    06_课题知识卡.md
    07_研究问题卡.md
    Codex同步规则.md
  文献推荐/
  论文阅读/
  实验仿真机理/
  课题知识库/
```

使用建议：
- 每次让我推荐文献时，保存到 `文献推荐/`。
- 每次让我读一篇论文时，保存到 `论文阅读/`。
- 每次分析实验、Abaqus/仿真、机理、异常结果时，保存到 `实验仿真机理/`。
- 每次形成稳定概念、研究假设、方法套路时，保存到 `课题知识库/`。

你给我的 `D:\Program Files\Obsidian` 是软件安装路径，不是 Vault 路径。不要把模板放进安装目录。后续需要你提供实际 Vault 路径，例如 `D:\Obsidian\ResearchVault`。
