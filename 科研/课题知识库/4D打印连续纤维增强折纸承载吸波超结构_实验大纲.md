# 4D 打印连续纤维增强折纸承载吸波超结构实验大纲

> 目标文章：用于可编程微波吸收的 4D 打印承载型折纸超结构  
> 核心主线：rGO/FCI/PLA 形状记忆吸波基体 + 连续纤维增强 + Miura-ori 折纸形态锁定 + 整体吸波调谐 + 单元级形态编码  
> 目标期刊风格：Nature Communications / Science Advances 类材料-结构-功能闭环叙事

---

## 1. 文章核心证据链

本研究需要证明的不是单一材料吸波性能，而是同一折纸构件中同时实现：

1. **材料基础**：rGO/FCI/PLA 提供介电/磁损耗和形状记忆锁定基础。
2. **纤维作用**：连续纤维改变有效介电损耗，同时提供载荷传递和电热激活通道。
3. **形态编程**：折纸单元可通过电热激活、机械设定和冷却锁定获得多个稳定折叠角。
4. **承载能力**：连续纤维增强折纸结构在锁定折叠状态下具备压缩/弯曲承载能力。
5. **吸波调谐**：整体折叠角改变等效厚度、传播路径和局域场分布，实现吸收频段迁移。
6. **阵列编码**：不同折叠角单元作为离散形态状态排列组装，实现阵列尺度后向散射调控。

## 12. 数据处理和关键指标

### 12.1 电磁指标

- RLmin：最低反射损耗。
- EAB：RL < -10 dB 的有效吸收带宽。
- 峰位迁移范围。
- 角度稳定性：不同入射角下 EAB 和 RLmin。
- 极化稳定性：TE/TM 或旋转极化下响应差异。
- RCS reduction：相对金属板或参考结构的后向散射降低。

### 12.2 材料指标

- ε′、ε″、μ′、μ″。
- tanδε、tanδμ。
- 衰减常数 α。
- 阻抗匹配 \|Zin/Z0\|。
- Cole-Cole 弧数量和变化。

### 12.3 4D 编程指标

- Tg 或可编程温区。
- 升温速率。
- 达到可编程温区时间。
- 形状固定率 Rf。
- 形状回复率 Rr。
- 折叠角误差。
- 循环后角度保持率。

### 12.4 力学指标

- 峰值载荷。
- 比承载能力，建议用最大载荷/自重。
- 平台载荷。
- 刚度。
- 能量吸收。
- 加载后形态保持。
- 加载后 RL 保持率。

## 14. 写作时的关键表述边界

1. 不要把连续纤维写成主导吸波相。更准确的表述是：连续纤维调节有效介电响应，并提供载荷传递和焦耳热激活通道。
2. 不要写成电热直接决定折叠角。真实机制应为：电热激活/软化 + 机械设定 + 冷却锁定。
3. 不要把平面参数筛选写成主创新。平面结果只作为折纸结构参数选择依据。
4. 不要把阵列编码写成机器学习或逆向设计，除非有充分算法和验证。
5. 与机械重构 Miura-ori 吸波结构区分时，重点放在 4D 打印、形态锁定、连续纤维电热激活和单元级编码。
