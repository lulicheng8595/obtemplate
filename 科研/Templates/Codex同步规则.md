# Codex 同步规则

## 默认落库范围

以后只要讨论内容与论文、文献、实验、仿真、机理或课题知识有关，Codex 应优先询问是否保存到 Obsidian；当用户明确说“保存”“放进 Obsidian”“归档”“记下来”时，直接写入对应目录。

## 分类规则

- 文献推荐：保存到 `文献推荐/`
- 论文阅读、PPT、摘要、精读：保存到 `论文阅读/`
- 实验方案、实验结果、异常分析：保存到 `实验仿真机理/`
- Abaqus、COMSOL、CST、MATLAB、Python 仿真：保存到 `实验仿真机理/`
- 机理解释、模型假设、证据链：保存到 `实验仿真机理/`
- 稳定概念、课题假设、方法套路、写作素材：保存到 `课题知识库/`

## 文件命名

推荐格式：

```text
YYYY-MM-DD_主题关键词.md
```

论文阅读建议：

```text
YYYY_第一作者_期刊_关键词.md
```

例如：

```text
2026_Feng_SciAdv_4D打印高熵陶瓷超材料吸波.md
```

## 每次写入必须包含

- YAML frontmatter
- 标签
- 来源或触发对话
- 一句话总结
- 对用户课题的关系
- 下一步动作

## 不保存的内容

- 与科研无关的闲聊
- 临时命令输出
- 未验证的网页碎片，除非明确标注“待核验”
- 用户未确认的个人敏感信息
